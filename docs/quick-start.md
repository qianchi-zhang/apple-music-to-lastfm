# 完整扩展使用指南

当前版本：扩展 0.1.0，算法 0.3.111；开发预览，未上架商店。需要 Chrome 103 或更新版本。

已安装用户请先下载新版 ZIP，并用其中 `browser-extension` 目录的内容覆盖**原来已加载的目录**，保留原路径；不要卸载扩展或清除其数据。在 `chrome://extensions` 对原扩展点击重新加载，关闭旧余音页面后重新打开，再到「设置 → 更新个人后台」更新原实例一次。重新加载不会自动下载新版本；仅换前端也不能更新云端逻辑。此次更新保留现有连接和记录。

## 获取与安装

安装网页只提供下载、安装说明和问题排查；Cloudflare 部署、账户连接及开始记录都在**完整扩展**里完成。不要在安装网页填写平台凭据。已有个人后台的用户可用网页中的单独入口打开控制台，这不会把后台导入扩展。

维护者提供 `browser-extension.zip`；有仓库访问权的用户也可从成功的 GitHub Actions 运行下载 `browser-extension` artifact。Actions 下载的外层归档需先解压，再解压里面的扩展 ZIP。

在 Chrome 地址栏输入 `chrome://extensions`，开启开发者模式，点击「加载已解压的扩展程序」，选择包含 `manifest.json` 的 `browser-extension` 目录。点击扩展图标打开完整控制台，无需启动本地服务或安装 npm。

## 连接服务

扩展使用分步引导。当前连接状态决定可进入的步骤及可用操作；每一步的成功或错误提示都出现在当前操作附近。遇到错误时先按提示重试、检查状态或返回对应步骤，不必从头部署。

1. **Cloudflare**：在官网登录自己的账户，按扩展引导申请仅限该账户的临时 Token，需要 Workers Scripts 编辑、Workers KV Storage 编辑及 Account Settings 读取。官方模板可能默认附带其他权限，需核对并移除。首次账户若没有 workers.dev 子域名，先在 Cloudflare 完成设置。填写 Token 并验证时允许访问 Cloudflare API；选择账户后，点击安装会先请求本次个人后台网址的访问权限，同意后继续完成部署。期间保留标签页。
2. **Apple Music**：在同一 Chrome 登录 `music.apple.com`，仅保留一个匹配的 Apple Music 标签页。回到扩展点连接，允许相应站点权限；扩展将凭据送到你自己的后台验证和保存。缺少官网标签页或尚未登录时，连接按钮下方会显示原因和官网入口；完成后回来重新连接。多个官网标签页时会提示关闭多余页面。
3. **Last.fm**：按当前页面显示的回调地址申请自己的 API 应用，直接在此保存 API Key 和 Shared Secret，再点击「前往 Last.fm 授权」。仅官网同意页另开标签页；授权完成后自动回到当前连接页，读取真实账户状态。无需另开管理台或复制管理钥匙解锁。原 Callback URL 不变。
4. **开始记录**：三项连接完成后显示「设置已完成」及当前 Last.fm 账户，点击「开始自动记录」即可，无需额外第四步或账户勾选。授权或刷新不会自动开启记录。首次开始建立当前历史基线，不补传暂停期间的历史。等开启成功后播放新歌。

管理钥匙可在当前页面的「设置」中复制备份。它保存在本浏览器的 `chrome.storage.local`，不是加密钥匙串；卸载或清除扩展数据会丢失本地信息。

**卸载或禁用扩展不会停止 Cloudflare 后台。** 如需停止记录，请先在余音暂停并确认成功，再卸载。暂停不删除凭据、队列、云端历史或 Last.fm 已接受的记录；永久删除需分别到对应平台处理。本版不提供丢失本地安装信息后的导入恢复界面。详见 [数据与隐私说明](data-and-privacy.md)。

不需要 Apple Developer Program 账户；当前连接依赖已登录的 Apple Music 网页和扩展助手，凭据有效期受 Apple 控制。

第一次使用 Cloudflare，可照着 [获取 API Token 的六步指南](cloudflare-token.md) 操作。控制台的个人后台步骤也默认展开同一份指引，包含官网入口、三列权限选择表、账户范围和复制后如何继续安装；已有 Token 可直接跳到输入框。

## 外观

主控制台「设置 → 外观」可选择「浅色」「深色」「跟随系统」。默认跟随系统外观；选择浅色或深色后固定使用相应外观。偏好以独立 key 保存在本浏览器的 `chrome.storage.local`，不跨设备同步，也不修改后台配置。若保存失败，当前页仍可使用已选择的主题，页面会提示偏好未保存；重新打开时可能恢复为之前设置。

安装指南和旧连接 popup 只跟随系统，不继承主控制台选择的固定主题。当前版本采用「余音」控制台：顶部「聆听记录／连接设置／设置」导航，连接操作在居中的底部进入面板完成，按日期分组展示最近 10 首。「查看更多」打开已连接用户的 Last.fm 主页。主界面提供浅色、深色与系统外观。

## 日常操作与故障恢复

后台开启后约每三分钟自动检查，另有 Apple 历史更新和识别延迟；关闭控制台不影响远端后台运行。返回扩展时会检查状态，也可以在连接设置底部刷新；记录页显示时会只读刷新最近记录。右上角记录状态可打开开始或暂停面板，恢复时无需账户勾选。暂停会停止后续采集和重试；恢复时重新建立播放基线，并继续处理已有队列，因此不要为了催促一首歌提交而反复暂停、开始。

- 权限被拒绝：根据 Chrome 提示允许扩展访问所需官网及个人后台，再重试对应步骤。
- 部署中断：保留原账户，重新输入同一账户的有效 Token 并继续；恢复流程不等于上传新版本。
- Cloudflare 重新设置：在已连接页直接点击「重新连接 Cloudflare」，重新验证原账户 Token 后点「连接并继续」，会原地更新已有后台代码并检查新版功能是否生效，沿用原有连接和记录。若提示等待更新生效，稍后检查后台状态，无需重复安装。
- 后台需要更新：在当前页面「设置 → 更新个人后台」重新验证原账户 Token，点击更新。只更新本扩展拥有的同一实例，继承原存储与密钥，保留账户连接和记录；不需要重新安装。更新会重新加载云端代码，可能短暂影响正在进行的请求。 0.3.106 用户重新加载扩展后，可经此入口原地升级到 0.3.111，无需重新授权 Apple Music 或 Last.fm；健康与记录接口均返回新版本和固定摘要后才确认更新成功。
- 后台运行故障：即使服务网址仍可访问，Apple 或 Last.fm 最近一次读取、提交失败也会显示具体问题；记录仍开启时可继续暂停。临时错误沿用原后台的自动重试，不需要重新安装。
- Apple 凭据失效：重新登录 Apple Music 网页，再从扩展连接。
- Last.fm 更换账户：真正换到另一账户会暂停记录。若还有原账户的待提交歌曲，先在 Last.fm 官网退出当前账户并登录提示中的原账户，再回到余音重新授权、手动开始，原队列会继续处理；不会把旧队列提交到新账户，也不会自动删除。换回原账户后可查看其历史。
- Last.fm 未连接：检查应用回调地址、应用配置和官方授权账号；连接成功后刷新扩展。
- 暂无新记录：确认已开启、等待 Apple 历史更新及自动检查，查看右上角状态和错误提示。不要通过新建部署来清理未知错误。
- 曲目有记录但无封面：新版优先按原始数字 `track_id` 从 Apple 公开 ID 接口读取封面，资料库 ID 使用原生接口；不使用 Last.fm 匹配后的文字搜索。重新加载扩展后通过「重新连接 Cloudflare」更新已有后台一次，不必重新授权音乐账户。若仍缺图，Network 中 artwork 响应会包含 `artwork_status`、`stage` 和适用的 `apple_http_status`，可据此排查；不需要提供请求标头或凭据。
- 刷新时的封面：最近十首的有效图片地址会缓存在扩展本地，刷新或重新打开可直接复用，最长七天。只有缺少、过期或加载失败时重新查询，超出最近十首的条目会清理。此缓存更新只需重新加载扩展，无需再次更新 Cloudflare 后台。

不要把 Token、Shared Secret、会话密钥或管理钥匙粘贴到 Issue、聊天或截图。遇到错误可提供步骤、版本、错误文字和脱敏截图。

当前支持明确点击后原地更新本扩展创建的后台；不支持静默自动升级、导入其他后台或丢失管理钥匙后的界面恢复。Windows、长时间运行和异常恢复的实机验收仍待补充，这些项目属于预览版已知验收边界。

## 开发者本地预览与验证边界

普通用户无需 npm。开发者可执行 `npm run preview:extension`，打开 `http://127.0.0.1:8794/` 体验本地隔离预览。预览中的 Cloudflare 部署、Apple Music、Last.fm 授权和记录均为模拟账户，所有状态只在内存中保存，刷新即重置；不会读取真实凭据或写入真实后台。可用 `npm run preview:extension -- --port 8798` 改用独立端口。`?demo=ledger` 展示十条模拟记录，`?demo=connected` 展示记录页，`?demo=ready` 展示开启前确认，`?demo=lastfm` 展示待授权状态，`?demo=error` 展示部署错误。

主题预览可使用 `?theme=light`、`?theme=dark`、`?theme=system`，与 demo 参数组合时用 `&`。模拟主题存储不持久，刷新后回到 URL 选项；未指定时回到自动。

Apple Music 连接提示可用 `?demo=apple&apple=missing` 预览缺页，`apple=multiple` 预览多页，`apple=signed-out` 预览未登录；均为隔离模拟，不读取真实标签页或凭据。

自动测试和本地隔离预览不等于完整真实链路验收。发布前已有用户确认更新后台后新播放成功提交，但 Windows、长时间运行及完整暂停恢复仍需补充实测。版本与验证范围以[当前发布说明](releases/v0.1.0.md)为准。
