# 数据与隐私说明

适用版本：扩展 0.1.0、固定算法 0.3.111。更新日期：2026-10-29。本文说明本版本的实际数据流，不代表已完成 Chrome 商店隐私披露或认证。

## 数据在哪里

| 数据                                              | 存储及用途                                                                                                                                                                                     |
| ------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Cloudflare API Token                              | 在当前扩展页的内存中用于验证和部署，请求发送到 `api.cloudflare.com`；不保存到扩展持久存储或个人 Worker。成功后清除部署客户端；失败时可能保留到本页重试或关闭。                                 |
| 个人后台地址、Cloudflare 账户及资源标识、管理钥匙 | 保存在本机 `chrome.storage.local`，不是系统加密钥匙串。管理钥匙也配置为个人 Worker 的 secret，用于鉴权管理请求；不要向他人提供。                                                               |
| Apple Music 授权信息                              | 扩展从已登录的 `music.apple.com` 页面读取 MusicKit 的 developer token 和 music user token，不读取账户密码或 Cookie；传给用户自己的后台，在 Durable Object 存储及 KV 中保存，用于读取最近播放。 |
| Last.fm API 应用和会话                            | API Key、Shared Secret、授权后取得的 session key 与用户名存于用户自己的后台。扩展保存成功后清空凭据输入，不把这些凭据另存为本机持久副本。                                                      |
| 歌曲、播放时间、记录状态                          | 用户自己的后台保存算法账本、待识别及待提交队列、匹配缓存和账户归属索引。最近记录、两种待处理队列分别有 1000 项上限；页面只展示最近 10 首，展示范围不代表全部云端数据范围。                     |
| 封面与外观                                        | 本机持久缓存最近 10 首的安全封面 URL、曲目标识、过期时间与作用域摘要，最长七天；离开最近列表、过期、账户变化或图片失效时清理。外观偏好也仅保存在当前浏览器。                                   |

## 数据发到哪里

- **Cloudflare**：接收部署请求，并在用户自己的账户运行后台、保存上述云端数据。后台开启后即使关闭控制台，仍可定时检查播放。
- **Apple**：后台向 Apple Music 接口发送必要授权信息并读取播放与歌曲信息；公开曲目 ID、搜索和封面查询也可能使用 iTunes 接口。
- **Last.fm**：官网处理用户授权；后台调用 API 查询元数据并提交歌曲名、歌手、播放时间，以及适用的专辑、专辑歌手、MBID 和时长等字段。
- **MusicBrainz**：固定算法可能按歌曲、歌手、ISRC 等元数据查询发行与匹配信息。
- **Apple 图片服务**：浏览器直接请求 `*.mzstatic.com` 加载封面。图片使用不发送 Referer 的设置，但图片服务仍会收到正常网络请求。

记录引擎包含需另配环境凭据的 Spotify、ListenBrainz 可选功能；本版安装器不设置这些凭据，新安装默认不启用这些分支。不存在“全部数据都只在浏览器本地处理”的保证。Cloudflare、Apple、Last.fm 等平台各自的数据处理仍受对应平台规则影响。

## 暂停、卸载与删除

暂停记录会停止后续采集和重试并取消自动调度；它不会删除保存的凭据、待处理歌曲或历史。恢复记录仍可能处理原账户已有的待提交队列。

卸载、禁用扩展或关闭 Chrome **不会停止云端后台**。卸载前请先在余音暂停并确认成功。卸载或清除扩展数据会丢失本地安装信息和管理钥匙；当前版本没有界面导入恢复功能，请提前备份管理钥匙。

如需永久移除，请在自己的 Cloudflare 账户删除对应 Worker 与存储资源，并按需要在 Apple、Last.fm 撤销授权。Last.fm 已接受的记录不会随扩展或 Cloudflare 资源删除，需到 Last.fm 单独处理。

遇到问题，请只提供版本、步骤、固定错误提示和脱敏截图；不要提交 Token、Shared Secret、会话密钥、管理钥匙、请求标头或包含授权参数的回调网址。
