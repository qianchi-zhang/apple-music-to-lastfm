# v0.1.0 · 首个公开预览版

Apple Music to Last.fm（余音）的首个公开预览版，版本 **0.1.0**。

## 为什么做这个工具

我们用 Apple Music 听歌，也希望在 Last.fm 留下自己的聆听历史。但 Apple Music 没有内置直接连接 Last.fm 的功能。

余音用来补上这段连接：把听过的歌曲记录到 Last.fm。完成设置并开启记录后，就可以继续按平时的习惯听歌，日后回看自己的音乐足迹。

## 功能

- 在同一个扩展页面完成个人 Cloudflare 后台、Apple Music 和 Last.fm 三步连接。
- 自托管后台定时记录播放，授权后需主动开始，可暂停和恢复。
- 展示最近十首聆听，按 Apple 原曲目 ID 获取封面，安全图片 URL 在本机最多缓存七天。
- 支持浅色、深色、系统外观、键盘操作及窄屏布局。
- 运行故障显示明确原因；Last.fm 换账户时暂停并保护原账户待提交队列。

## 安装

需要 Chrome 103+、Apple Music、Cloudflare 账户及自己的 Last.fm API 应用。普通用户无需 npm，本版未上架 Chrome 商店。

下载 `browser-extension.zip` 并解压。在 `chrome://extensions` 开启开发者模式，点击「加载已解压的扩展程序」，选择解压后包含 `manifest.json` 的 `browser-extension` 目录。点击扩展图标，按向导连接三项服务，最后点击「开始自动记录」。

已有开发版用户需用新包内容覆盖原加载目录，保留原路径，不卸载、不清除数据；重新加载后关闭旧控制台再打开，并在「设置 → 更新个人后台」更新原实例一次。新仓库和应用版本重置不影响已拥有的后台标记、连接与记录。

**卸载或禁用扩展不会停止云端记录。** 请先暂停并确认，提前备份管理钥匙。暂停不删除凭据或 Last.fm 已接收记录；本版没有丢失本地安装信息后的导入恢复界面。

## 验证与边界

发布包含应用回归、31 项固定算法回归、类型检查及源码／ZIP 一致性检查。首次公开前已有用户反馈更新个人后台后，新播放成功记录到 Last.fm；这项为用户反馈，不是对每次播放或长期运行的保证。

Apple 最近播放为轮询快照，可能延迟或遗漏，不能保证捕获每次播放或恰好一次提交。长时间运行、Windows 和完整暂停恢复仍需补充实机验证；本次发布标为预览版。页面最近十首不是全部云端数据范围，后台还保存账本和待处理队列；歌曲元数据会向相关平台发送。

安装包同时提供 `SHA256SUMS`，可按附件中的摘要校验 ZIP。
