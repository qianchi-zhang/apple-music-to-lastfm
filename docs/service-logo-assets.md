# 服务 Logo 素材

连接页三个阶段的服务标识使用官方原始素材，替换此前的通用音符、云朵和 `as` 字母占位。日志侧栏及 Apple Music 连接示意复用同一份素材。图片作为装饰呈现，相邻文字保留服务名称。

| 本地文件                                                | 官方来源                                                                                                                                                                                                                                    | 使用方式                              |
| ------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------- |
| `apps/browser-extension/assets/service-apple-music.svg` | [Apple Music Identity Guidelines](https://marketing.services.apple/apple-music-identity-guidelines) 中的 [官方 Icon 下载包](https://apple.co/am-icon-2020)，原文件 `AppleMusic_Icon_Color/RGB/SVG/Small/Apple_Music_Icon_RGB_sm_073120.svg` | 官方彩色小尺寸图标，保持 SVG 原始内容 |
| `apps/browser-extension/assets/service-cloudflare.svg`  | [Cloudflare Docs](https://developers.cloudflare.com/) 使用的[独立云标 SVG](https://developers.cloudflare.com/_astro/logo.te5VL_aD.svg)                                                                                                      | 原始橙色云标，保持 66:30 比例         |
| `apps/browser-extension/assets/service-lastfm.png`      | [Last.fm 官网](https://www.last.fm/) 使用的[移动端 Logo](https://www.last.fm/static/images/logo_static_mob@2x.277314e1999f.png)                                                                                                             | 原始透明红色字标，保持 180:48 比例    |

素材于 2026-10-25 获取；均未重新绘制、变色、裁剪或拉伸。Cloudflare 与 Last.fm 使用白色容器，在浅色与深色界面中保持原色。三份素材随扩展打包，界面不请求外部图片。
