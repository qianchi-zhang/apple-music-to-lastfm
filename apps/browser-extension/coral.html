步骤 3 / 4

连接 Last.fm

授权的 Last.fm 账户

3.1配置 API 应用待配置修改

先在 Last.fm 创建 API 应用。填写时使用下方回调地址，再将获得的两项凭据填回这里。

打开 Last.fm 创建 API 应用

应用主页

请先完成个人后台设置

Callback URL（回调地址）

请先完成个人后台设置
创建应用时怎么填写？

应用名称可以自定，邮箱填写你自己的地址，主页使用上方的“应用主页”。Callback URL 使用上方的完整回调地址。

创建完成后，将应用页面给出的 API Key 和 Shared Secret 填到下方。这两项是应用凭据，不是 Last.fm 账户密码。

3.2授权 Last.fm 账户等待应用配置

先完成 3.1 的应用配置，再继续授权。

请先保存应用配置。

  1. 复制管理钥匙，在下一页解锁你自己的个人后台。

  2. 打开个人后台，粘贴钥匙解锁，完成 Last.fm 官方授权。

  3. 完成后回到这里，页面会自动检查连接。也可以手动检查。
