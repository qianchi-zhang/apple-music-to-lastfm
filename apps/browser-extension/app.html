如何获取 Cloudflare API Token？
  1. 在 Cloudflare 官网登录，选择你要部署的账户。
  2. 使用 Edit Cloudflare Workers 模板，仅保留 Workers Scripts（Edit）、Workers KV Storage（Edit） 和 Account Settings（Read）。移除模板附带的其他权限。
  3. 创建后复制 Token 并粘贴到上方。若账户尚无 workers.dev 网址，先在 Workers & Pages 完成子域名设置，再回来继续。

新后台默认暂停，确认音乐账户后再开始记录。

配置 Last.fm 应用

在 Last.fm 创建 API 应用。应用名称可填 Apple Music Scrobbler；联系邮箱填你自己的邮箱。回调地址填写下方值，应用主页可填你的后台网址。

请先完成个人后台设置

官网创建后会显示 API Key 和 Shared Secret，请分别复制到这里，不要填写账户密码。

允许你的账户连接

请先保存应用配置。

  1. 复制管理钥匙，打开个人后台并粘贴解锁。
  2. 在后台点击连接 Last.fm，到官网核对账号并允许。
  3. 完成后回到此页；这里会自动检查授权结果。
