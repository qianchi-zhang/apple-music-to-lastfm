个人后台已经准备好

Cloudflare 是运行个人后台的平台。API Token（访问令牌）是允许余音替你安装后台的凭证，下面会带你一步步创建。

首次设置，从下面开始
如何获取 API Token跟着 Cloudflare 官网操作

  1. 登录 Cloudflare，准备个人后台的网址

    还没有账户？先在 Cloudflare 注册并验证邮箱。打开 Workers & Pages，选择本次要安装后台的账户；首次使用时，按页面提示完成 Workers 初始化。

    在 Your subdomain（你的子域名）处确认已有 xxx.workers.dev。余音会使用这个网址，不需要购买或接入域名。

    打开 Workers & Pages

  2. 打开 API Tokens，创建自定义令牌

    点击下面的链接。手动查找时，入口是：右上角头像 → My Profile（我的个人资料） → API Tokens。

    打开 API Tokens 页面

    点击 Create Token（创建令牌），找到 Create Custom Token（自定义令牌），点击 Get started（开始使用）。名称可以填写「余音部署」。

  3. 在 Permissions 中添加这三行

    每行有三个下拉框，依次选择下表内容。用 Add more（添加更多）添加下一行。

    Permissions（权限）：类别 → 权限 → 级别
    类别 权限 级别
    帐户Account Workers KV 存储Workers KV Storage 编辑Edit
    帐户Account Workers 脚本Workers Scripts 编辑Edit
    帐户Account 帐户设置Account Settings 读取Read

    这三行的第一项都选 Account（账户），不需要添加 Zone（区域）或 DNS 权限。

  4. 把访问范围限定到你的部署账户

    找到 Account Resources（账户资源），选择 Include（包括），再指定第 1 步选择的那个账户。

    如果有多个账户，只选择这次安装要使用的一个。其余可选项可保留默认；如果设置有效期，确保 Token 在本次安装期间有效。

  5. 生成 Token，复制完整内容

    点击 Continue to summary（继续到摘要），核对三项权限和账户，再点击 Create Token。

    在结果页点击 Copy（复制）。完整 Token 只显示一次，请复制那一整串内容；这里需要的是 Token 本身，不是名称、Account ID 或 Global API Key。

  6. 回到余音，验证并安装

    把 Token 粘贴到下面，点击「验证 Token」。看到部署账户后，选中与第 1 步相同的账户，再点击「安装个人后台」。安装成功会进入 Apple Music 连接。

    查看 Cloudflare 官方创建说明
